# MCP Database — SportRentalHybrid

Ten projekt używa bazy `sr` na Azure PostgreSQL.

**MCP Server:** `postgres-sr`
**Tool:** szukaj toola z prefiksem `postgres-sr` (np. `mcp5_query` lub podobny)
**Baza:** `sr` na `eduedu.postgres.database.azure.com`

Nie używaj innych serwerów postgres (electric, procviewer, toolkit, am, voicebotdemo) chyba że user jawnie poprosi.
